🌐 ¿Qué es HTML?

Descubre la diferencia entre lenguajes de programación y lenguajes de marcado

📝 HTML NO es un lenguaje de programación

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto).

¿Qué es un lenguaje de marcado?

Un lenguaje de marcado es un sistema de anotaciones que se puede leer tanto por humanos como por máquinas. Se utiliza para estructurar y presentar contenido, NO para crear lógica o algoritmos.

❌ Lo que HTML NO hace:

  • No ejecuta cálculos matemáticos
  • No toma decisiones (if/else)
  • No maneja bucles (for/while)
  • No almacena variables
  • No crea funciones

✅ Lo que HTML SÍ hace:

  • Estructura el contenido
  • Define títulos, párrafos, listas
  • Organiza la información
  • Conecta páginas web (enlaces)
  • Integra multimedia

🏗️ Estructura Mínima de HTML

Toda página HTML necesita estos elementos básicos:

Código de ejemplo:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi página</title>
</head>
<body>
    <h1>Hola Mundo</h1>
</body>
</html>
<!DOCTYPE html> - Declara que es HTML5
<html> - Elemento raíz del documento
<head> - Información del documento (no visible)
<body> - Contenido visible de la página
