# 🌐 Web Explicativa: ¿Qué es HTML?

## 📋 Descripción

Esta es una página web educativa que explica de manera clara y visual que **HTML NO es un lenguaje de programación**, sino un **lenguaje de marcado**. Incluye demostraciones interactivas con JavaScript para mostrar la diferencia entre código embebido y código externo.

## 🎯 Objetivos Educativos

- ✅ Explicar que HTML es un lenguaje de marcado, no de programación
- ✅ Mostrar la estructura mínima de un documento HTML
- ✅ Demostrar la integración de HTML con JavaScript
- ✅ Comparar código JavaScript externo vs interno
- ✅ Proporcionar ejemplos prácticos e interactivos

## 📁 Estructura de Archivos

```
html.js/
├── index.html          # Archivo HTML principal
├── styles.css          # Estilos CSS externos
```

## 🚀 Cómo Usar

1. **Abrir el archivo**: Abre `index.html` en tu navegador web
2. **Leer la explicación**: Navega por las secciones para entender HTML
3. **Probar la interactividad**: 
   - Haz click en el botón azul para ver JavaScript externo
   - Haz click en el botón verde para ver JavaScript interno
   - Abre la consola (F12) para ver los mensajes

## 📚 Conceptos Explicados

### HTML como Lenguaje de Marcado
- **No ejecuta lógica**: No puede hacer cálculos ni tomar decisiones
- **Estructura contenido**: Organiza información en títulos, párrafos, listas
- **Presentación básica**: Define qué es cada elemento, no cómo se ve
- **Integración**: Trabaja con CSS (estilos) y JavaScript (funcionalidad)

### Estructura Mínima HTML
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi página</title>
</head>
<body>
    <h1>Hola Mundo</h1>
</body>
</html>
```

### JavaScript: Externo vs Interno
- **Externo** (`script.js`): Código separado, reutilizable, mantenible
- **Interno** (dentro de HTML): Código embebido, específico, rápido de implementar
