# Operadores de JavaScript - Guía Completa

Una web moderna y responsive con el contenido completo de operadores de JavaScript, traducido al español y optimizada para presentaciones en clase.

## 🚀 Características

- **Diseño Moderno**: Interfaz limpia y profesional con gradientes y sombras sutiles
- **Sidebar Interactivo**: Navegación lateral con scroll automático a secciones
- **Responsive**: Optimizado para pantallas de 11-23 pulgadas y móviles
- **Contenido Completo**: Todos los operadores de JavaScript con ejemplos prácticos
- **Animaciones Suaves**: Transiciones y efectos visuales para mejor experiencia
- **Accesibilidad**: Navegación por teclado y tooltips informativos

## 📁 Estructura de Archivos

```
01-js-logica/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # Funcionalidad JavaScript
└── README.md           # Este archivo
```

## 🎯 Cómo Usar

### Para Presentaciones en Clase

1. **Abrir la web**: Simplemente abre `index.html` en tu navegador
2. **Navegar por secciones**: Usa el sidebar izquierdo para saltar a cualquier tema
3. **Ocultar/Mostrar sidebar**: Haz clic en el botón hamburguesa (☰) en la esquina superior izquierda
4. **Scroll automático**: Al hacer clic en cualquier tema del sidebar, la página se desplazará suavemente a esa sección

### Atajos de Teclado

- **Ctrl/Cmd + B**: Alternar sidebar
- **Escape**: Cerrar sidebar (en móviles)

## 📱 Responsive Design

- **Desktop (11-23 pulgadas)**: Sidebar fijo visible, contenido principal con margen
- **Tablet (768px y menos)**: Sidebar oculto por defecto, se puede mostrar con el botón
- **Móvil (480px y menos)**: Diseño optimizado para pantallas pequeñas

## 🔧 Personalización

### Cambiar Colores

Edita las variables CSS en `styles.css`:

```css
:root {
    --primary-color: #3b82f6;    /* Color principal */
    --primary-dark: #2563eb;     /* Color principal oscuro */
    --accent-color: #f59e0b;     /* Color de acento */
    /* ... más variables */
}
```

### Agregar Contenido

Para agregar nuevas secciones:

1. Añade una nueva `<section>` en `index.html`
2. Agrega el enlace correspondiente en el sidebar
3. El JavaScript detectará automáticamente la nueva sección
