Operadores de JavaScript

Los operadores de JavaScript son símbolos especiales que realizan operaciones en operandos (valores y variables).

Ejemplo Básico

// Asignar el valor 5 a x
let x = 5;
// Asignar el valor 2 a y
let y = 2;
// Asignar el valor x + y a z:
let z = x + y;

Suma en JavaScript

El Operador de Suma (+) suma números:

let x = 5;
let y = 2;
let z = x + y;

Multiplicación en JavaScript

El Operador de Multiplicación (*) multiplica números:

let x = 5;
let y = 2;
let z = x * y;

Operadores Aritméticos de JavaScript

Los Operadores Aritméticos se utilizan para realizar operaciones aritméticas en números:

Ejemplo de Operadores Aritméticos

let a = 3;
let x = (100 + 50) * a;

Operadores de Asignación de JavaScript

Los operadores de asignación asignan valores a variables de JavaScript.

El Operador de Asignación de Suma (+=) suma un valor a una variable.

Asignación

let x = 10;
x += 5;

-= x -= y x = x - y

Comparación de Cadenas en JavaScript

Todos los operadores de comparación anteriores también se pueden usar en cadenas:

Ejemplo

let text1 = "A";
let text2 = "B";
let result = text1 < text2;

Ten en cuenta que las cadenas se comparan alfabéticamente:

Ejemplo

let text1 = "20";
let text2 = "5";
let result = text1 < text2;

Suma de Cadenas en JavaScript

El + también se puede usar para sumar (concatenar) cadenas:

Ejemplo

let text1 = "John";
let text2 = "Doe";
let text3 = text1 + " " + text2;

El operador de asignación += también se puede usar para sumar (concatenar) cadenas:

Ejemplo

let text1 = "Qué día tan ";
text1 += "agradable";

El resultado de text1 será:

Qué día tan agradable

Sumar Cadenas y Números

Sumar dos números devolverá la suma como un número, como 5 + 5 = 10.

Sumar un número y una cadena devolverá la suma como una cadena concatenada, como 5 + "5" = "55".

Ejemplo

let x = 5 + 5;
let y = "5" + 5;
let z = "Hola" + 5;

El resultado de x, y, y z será:

10
55
Hola5

Operadores Bitwise de JavaScript

Los operadores bitwise trabajan en números de 32 bits.

Cualquier operando numérico en la operación se convierte en un número de 32 bits. El resultado se convierte de vuelta a un número de JavaScript.

Operador Descripción Ejemplo Igual a Resultado Decimal
& AND 5 & 1 0101 & 0001 0001 1
| OR 5 | 1 0101 | 0001 0101 5
~ NOT ~ 5 ~0101 1010 10
^ XOR 5 ^ 1 0101 ^ 0001 0100 4
<< desplazamiento izquierda 5 << 1 0101 << 1 1010 10
>> desplazamiento derecha 5 >> 1 0101 >> 1 0010 2
>>> desplazamiento derecha sin signo 5 >>> 1 0101 >>> 1 0010 2

Nota: Los ejemplos anteriores usan ejemplos de 4 bits sin signo. Pero JavaScript usa números con signo de 32 bits. Debido a esto, en JavaScript, ~ 5 no devolverá 10. Devolverá -6.

Operadores Ternarios de JavaScript

El operador ternario es una forma abreviada de la estructura condicional if. Su sintaxis es condición ? valorSiVerdadero : valorSiFalso.

Ejemplo

let edad = 18;
let mensaje = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
// mensaje será "Mayor de edad"
